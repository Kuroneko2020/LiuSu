# 留素 LiuSu

留素是桌面端照片拼版工具：把多张照片快速排到 6 英寸相纸上，导出后打印、裁切、留存。

## 核心用户目标

- 快速导入照片。
- 在固定相纸尺寸内选择二 / 四 / 九等拼版模板。
- 对每个槽位做旋转、镜像、填充、裁切偏移和替换。
- 叠加可扩展边框，例如胶片尺孔、白边、拍立得边、裁切辅助线。
- 保证预览、导出、打印前检查一致。
- 输出适合打印的图片文件。

## 第一阶段范围

- 6 英寸相纸页面模型。
- 二 / 四 / 九基础模板。
- 图片导入、槽位填充、槽位编辑。
- 背景色或基础背景设置。
- 可扩展边框系统第一版，胶片尺孔作为首个重点边框规格。
- 导出图片。
- 最小项目保存 / 打开能力。
- 最小测试与样张验证。

## 第一阶段明确不做

- 不做复杂修图：磨皮、滤镜市场、调色曲线、局部修复。
- 不做云同步、账号系统、素材商城。
- 不做大型图库管理。
- 不做移动端。
- 不原样保留旧版 UI；UI 重新设计。
- 不把旧版代码视为可直接复制的事实来源。

## 核心设计判断

- 模板负责照片槽位布局；边框负责装饰、孔洞、线条、留白、胶片尺孔等外观层；裁切标记负责打印裁切辅助。理由见 [ADR-0001](docs/决策/ADR-0001-模板与边框分层.md)。
- 渲染引擎负责把页面模型转换成预览图、缩略图和导出图，三者共享同一套几何事实，见[尺寸与渲染规则](docs/规范/尺寸与渲染规则.md)。
- UI 只负责操作入口和状态展示，不是最终几何真相。

## 待所有者确认的产品取舍

以下取舍尚未拍板，确认后应记录为 ADR：

1. 6 英寸相纸是否沿用旧版的 `148mm × 100mm`。
2. 默认导出 PPI 使用 300、600，还是做成用户设置。
3. 胶片尺孔第一版是否只做横向胶片边，还是同时支持竖向。
4. 首版是否需要打印机直连，还是只导出图片后由系统 / 外部软件打印。
