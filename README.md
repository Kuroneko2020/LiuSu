# 留素 LiuSu

留素是桌面端照片拼版工具：把多张照片快速排到 6 英寸相纸上，导出后打印、裁切、留存。

界面目标：干净、丝滑、灵动、高级。旧版 UI 不作参考，仅作反例；设计质量是本轮重做的重要目标。

产品本质（现阶段）：把照片导入，提供拼版布局、边框与裁切，产出可打印的页面。定位随需求演进，不固定——单张、二、四、九只是首批布局预设，不是产品边界（见 [ADR-0006](docs/决策/ADR-0006-产品定位与布局泛化.md)）。

## 核心用户目标

- 快速导入照片。
- 把导入的照片排进相纸页面：选择拼版布局（首批预设：单张全幅、二、四、九，模型可扩展），并对每个槽位做旋转、镜像、填充、裁切偏移和替换。
- 叠加可扩展边框，例如胶片尺孔、白边、拍立得边、裁切辅助线。
- 保证预览、导出、打印前检查一致。
- 输出适合打印的图片文件。

## 第一阶段范围

- 6 英寸相纸页面模型（档案化尺寸，不写死，见 [ADR-0003](docs/决策/ADR-0003-页面与打印机档案化.md)）。
- 通用槽位布局模型，首批预设：单张全幅、二、四、九（[ADR-0006](docs/决策/ADR-0006-产品定位与布局泛化.md)）。
- 图片导入、槽位填充、槽位编辑。
- 背景色或基础背景设置。
- 多档位 PPI 导出图片（见 [ADR-0004](docs/决策/ADR-0004-导出PPI多档位与仅导出.md)）。
- 最小项目保存 / 打开能力。
- 最小测试与样张验证。

## 第一阶段明确不做

- 不做复杂修图：磨皮、滤镜市场、调色曲线、局部修复。
- 不做云同步、账号系统、素材商城。
- 不做大型图库管理。
- 不做移动端。
- 不做打印机直连，只导出图片文件（[ADR-0004](docs/决策/ADR-0004-导出PPI多档位与仅导出.md)）。
- 暂不做边框系统与胶片尺孔，架构已预留（[ADR-0005](docs/决策/ADR-0005-第一阶段范围调整.md)）。
- 不原样保留旧版 UI；UI 重新设计。
- 不把旧版代码视为可直接复制的事实来源。

## 核心设计判断

- 模板负责照片槽位布局；边框负责装饰、孔洞、线条、留白、胶片尺孔等外观层；裁切标记负责打印裁切辅助。理由见 [ADR-0001](docs/决策/ADR-0001-模板与边框分层.md)。
- 渲染引擎负责把页面模型转换成预览图、缩略图和导出图，三者共享同一套几何事实，见[尺寸与渲染规则](docs/规范/尺寸与渲染规则.md)。
- UI 只负责操作入口和状态展示，不是最终几何真相。

## 已确认的关键取舍

- 尺寸不写死：6 英寸为首个页面档案；打印机档案化，预留尺寸校准功能（[ADR-0003](docs/决策/ADR-0003-页面与打印机档案化.md)）。
- 导出 PPI 多档位：300 / 600 / 自定义（72–1200），默认 300（[ADR-0004](docs/决策/ADR-0004-导出PPI多档位与仅导出.md)）。
- 首版只导出图片，不做打印机直连（[ADR-0004](docs/决策/ADR-0004-导出PPI多档位与仅导出.md)）。
- 胶片尺孔暂不开发，边框系统整体延后（[ADR-0005](docs/决策/ADR-0005-第一阶段范围调整.md)）。

## 未来方向（未排期）

- 尺寸校准功能：生成校准矩形 → 打印实测 → 输入实测值 → 软件计算偏移并保存到对应打印机档案。
- 打印机档案扩展：更多机型与相纸尺寸。
- 边框系统：胶片尺孔、白边、拍立得边等（架构见 [ADR-0001](docs/决策/ADR-0001-模板与边框分层.md)）。
