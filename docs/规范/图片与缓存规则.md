# 图片与缓存规则

本文规定图片读取、EXIF、缩略图、预览缓存和缓存 key 的基本规则。

## 核心结论

缓存 key 不能只包含图片路径。只包含路径会在同路径文件被替换时误命中旧缓存。

## 图片读取

- 图片读取必须统一处理 EXIF 方向。
- 预览、缩略图和导出必须使用同一套方向判断。
- 不得在 UI 层重复实现图片方向修正。
- 无法读取或格式不支持时，应返回可解释错误，不要静默生成空白导出。

## 图片状态

每个槽位至少需要表达：

- 原始图片路径或资源引用。
- 原始文件身份信息。
- 旋转角度。
- 镜像状态。
- 填充模式。
- 裁切偏移。
- 缩放或等价裁切参数。
- 替换 / 缺失 / 读取失败状态。

## 缓存 key 最低要求

缓存 key 至少包含：

- 原始绝对路径或稳定资源 ID。
- 文件大小。
- 文件修改时间。
- 预览目标尺寸或 `previewMaxEdge`。
- EXIF 自动方向结果或等价版本标识。
- 旋转。
- 镜像。
- 填充模式。
- 裁切偏移 / 缩放。
- 模板 ID 和模板参数。
- 边框 ID 和边框参数。
- 背景参数。
- 渲染算法版本。

新增滤镜、遮罩、边框、背景、裁切规则或导出算法后，也必须评估是否进入缓存 key。

## 缓存分层

推荐分层：

| 缓存 | 用途 | 特点 |
| --- | --- | --- |
| 原图信息缓存 | 文件尺寸、EXIF、可读性 | 小而稳定 |
| 缩略图缓存 | 图片列表和槽位缩略图 | 低清，响应快 |
| 槽位预览缓存 | 旋转、镜像、裁切后的槽位图 | 受槽位状态影响 |
| 页面预览缓存 | 模板、图片、边框、背景合成 | 受页面模型影响 |
| 导出缓存 | 默认不长期缓存，除非明确设计 | 必须避免误复用 |

## 失效策略

以下变化必须导致相关缓存失效：

- 图片文件大小或修改时间变化。
- 槽位旋转、镜像、填充、裁切变化。
- 模板切换或模板参数变化。
- 边框切换或边框参数变化（边框系统立项后适用）。
- 背景变化。
- 打印机档案或校准偏移变化（[ADR-0003](../决策/ADR-0003-页面与打印机档案化.md)）。
- PPI 或导出尺寸变化。
- 渲染算法版本变化。

## 测试要求

- 同路径替换图片后不能命中旧缩略图。
- 旋转 / 镜像 / 裁切变化后槽位预览更新。
- 边框变化后页面预览更新。
- EXIF 方向样本在预览和导出中一致。
- 缓存清理不删除用户原图或项目文件。
