# UI规则

本文规定留素 UI 重绘、QML 边界和交互规则。

## 核心结论

UI 可以重绘，但不能成为导出真相。最终页面尺寸、槽位几何、边框孔位、PPI 换算和导出顺序必须来自领域模型和渲染层。

## UI 负责什么

- 页面布局和视觉层级。
- 按钮、面板、菜单、快捷操作。
- 图片拖放、槽位选择、参数调整。
- 预览显示。
- 用户输入校验和错误提示。
- 调用应用服务执行命令。

## UI 不负责什么

- 最终导出像素尺寸。
- 相纸物理尺寸。
- 模板槽位真值。
- 胶片尺孔真实孔位。
- 图片 EXIF 方向算法。
- 缓存 key 拼接。
- 项目文件 schema。

## 状态流原则

推荐单向流：

```text
用户操作 -> UI 命令 -> 应用服务 -> 领域模型更新 -> 渲染 / 缓存失效 -> UI 订阅刷新
```

禁止让 QML 控件之间互相偷改底层事实，导致导出与屏幕显示不一致。

## 重绘原则

- UI 美观可以大胆重做，但业务模型不要跟着重写成 UI 形状。
- UI 组件应围绕用户任务分组：导入、模板、边框、槽位编辑、导出。
- 复杂视觉状态要有清晰命名，不要用大量匿名布尔值堆叠。
- 选中框、拖拽手柄、悬浮提示默认只在 UI 层显示，不进入导出。
- 所有影响导出的设置必须能在项目模型中找到对应字段。

## 内容稳定与材质边界

- 按内容职责判断材质，不按固定界面分区强制玻璃化；现行方向见 [ADR-0015](../决策/ADR-0015-克制材质与稳定内容.md)及[界面设计基准](../设计/界面设计基准.md)。
- 照片、纸面和用于观察比较的缩略图，不因装饰性悬停而位移、倾转、缩放或改变明暗。检查整个祖先容器链，视觉内容和命中坐标都要稳定。
- 容器光线反馈不能盖住照片；选中、拖放提示与必要编辑操作继续有效。用户主动取景、旋转、换页造成的内容变化不属于装饰运动。
- 效果图只提供被所有者明确认可的参考范围；不能从材质认可推导出布局、功能或产品范围授权。

## 验收要求

- 窗口缩放不改变导出结果。
- 预览缩放不改变页面真实比例。
- UI 切换模板、边框、图片状态后，导出使用同一状态。
- 关闭重开项目后，影响导出的 UI 设置能恢复。
- UI 层删除或重绘后，核心导出测试仍能运行。
- 悬停稳定检查需覆盖进入、停留、移动、离开、边缘和快速进出；场景坐标与照片像素均检查。运行截图、逐帧证据与自动测试不等于美术或手感已获所有者验收。
