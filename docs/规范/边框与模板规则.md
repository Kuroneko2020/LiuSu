# 边框与模板规则

本文规定模板、边框、胶片尺孔和裁切标记的职责边界。

## 核心结论

胶片尺孔属于可扩展边框系统，不属于二 / 四 / 九模板本体。

模板负责照片槽位怎么排；边框负责装饰、孔洞、留白、线条、胶片尺孔和外观层；裁切标记负责打印裁切辅助。

本分层决策的理由见 [ADR-0001](../决策/ADR-0001-模板与边框分层.md)。

## 职责划分

| 概念 | 负责 | 不负责 |
| --- | --- | --- |
| 模板 | 页面中有几个照片槽位、槽位位置、槽位比例、槽位间距 | 胶片孔、装饰线、纸张纹理、UI 选中框 |
| 边框 | 页面级或槽位级装饰、孔洞、白边、胶片尺孔、拍立得外观 | 决定照片数量和基础槽位布局 |
| 裁切标记 | 打印后裁切辅助线、角标、出血提示 | 改变照片实际布局 |
| UI 操作层 | 选中框、拖拽手柄、悬浮按钮、预览提示 | 进入最终导出，除非用户明确选择 |

## 禁止设计

禁止把需求写成：

```text
二张胶片模板
四张胶片模板
九张胶片模板
```

这种设计会让每个新边框都乘以每个模板，后续维护成本爆炸。

推荐写成：

```text
模板：二张 / 四张 / 九张
边框：无边框 / 胶片尺孔 / 白边 / 拍立得边 / 其它装饰边
```

## 边框规格模型

一个边框规格至少应描述：

- 边框 ID。
- 显示名称。
- 适用范围：页面级、槽位级，或二者都可。
- 几何参数：边距、孔位、孔尺寸、圆角、间距、线宽。
- 绘制层级：在图片前、图片后、页面最上层等。
- 是否影响可用图片区域。
- 是否进入导出。
- 参数默认值和合法范围。

## 胶片尺孔第一版建议

胶片尺孔可以先按页面级边框实现：

- 在页面两侧或上下生成重复孔洞。
- 孔洞尺寸和间距基于页面物理尺寸或归一化比例。
- 孔洞样式独立于模板数量。
- 不改变二 / 四 / 九模板的槽位定义。
- 是否压缩照片区、是否覆盖照片边缘，应作为边框参数或产品取舍明确。

## 边框与槽位的关系

边框分两类：

1. 不占位边框：叠加在页面上，不改变照片槽位。
2. 占位边框：会预留边距，实际照片可用区域缩小。

两类都可以存在，但必须在模型中显式标记。不得让边框绘制函数暗中改模板槽位。

## 测试要求

- 同一模板切换不同边框时，槽位基础数量不变。
- 同一边框套在二 / 四 / 九模板上都能渲染。
- 胶片尺孔孔位不由 QML item 尺寸决定。
- 边框参数进入项目文件和缓存 key。
- 边框关闭后导出不残留旧孔位缓存。
