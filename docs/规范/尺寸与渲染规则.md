# 尺寸与渲染规则

本文规定相纸尺寸、坐标系统、PPI、预览、缩略图和导出的同源规则。

## 核心结论

预览、缩略图和导出必须共享同一套页面模型和渲染管线。允许预览使用低分辨率缓存，但不允许预览和导出使用两套几何算法。

## 相纸尺寸

- 页面物理尺寸必须由统一配置或统一函数提供，UI、预览、导出和测试不得各自硬编码尺寸。
- 尺寸模型档案化，不写死单一数值（[ADR-0003](../决策/ADR-0003-页面与打印机档案化.md)）：6 英寸相纸是首个页面档案，未来新增尺寸走新档案。
- 首个目标机型为小米米家照片打印机 1S：热升华打印，输出密度 300 dpi，6 英寸相纸 `100mm × 148mm`；可打印区域与留白的毫米级数值以官方手册或实测核定后写入打印机档案，不得把搜索摘要直接当事实。
- 旧项目使用过的 `148mm × 100mm` 与 6 英寸标准一致，可作为页面档案初值参考；最终以核定结果为准。

## 坐标系统

推荐同时保留三种口径，但主来源必须清楚：

| 口径 | 用途 | 规则 |
| --- | --- | --- |
| 物理尺寸 mm | 打印、导出、模板设计 | 页面真实尺寸主来源 |
| 归一化坐标 | 模板和边框规格复用 | 不受 PPI 影响 |
| 像素坐标 px | 最终预览和导出位图 | 由 mm + PPI 派生 |

不得让屏幕像素、QML item 尺寸或窗口大小反向决定真实页面几何。

## PPI 规则

- PPI 是导出参数，不是 UI 缩放参数。
- 导出 PPI 采用多档位设置，不做单一固定值（[ADR-0004](../决策/ADR-0004-导出PPI多档位与仅导出.md)）：300 / 600 / 自定义（72–1200），默认 300；默认档位可被打印机档案推荐密度影响。
- 导出像素尺寸必须由物理尺寸和当前档位 PPI 推导。
- 不同档位输出只改变像素密度，不改变照片槽位的物理比例。

## 打印机档案与校准

- 打印机档案承载单台机型的可打印区域、留白、推荐输出密度等参数；档案可新增、可修改，不属于代码常量（[ADR-0003](../决策/ADR-0003-页面与打印机档案化.md)）。
- 预留尺寸校准流程，第一阶段不实现：软件生成校准矩形 → 用户打印并实测 → 输入实测尺寸 → 软件计算尺寸偏移 → 偏移保存到对应打印机档案。
- 校准偏移属于打印机档案参数，是页面几何到输出像素映射的输入之一；其变化必须导致页面预览与导出缓存失效。

## 渲染同源

以下输入必须对预览、缩略图、导出一致：

- 页面尺寸。
- 模板槽位矩形。
- 背景。
- 图片 EXIF 方向。
- 旋转、镜像、填充模式、裁切偏移。
- 边框规格和边框参数。
- 边框绘制顺序。
- 裁切标记。

## 绘制顺序

推荐基础顺序：

1. 页面背景。
2. 模板槽位底色或占位。
3. 槽位图片。
4. 单槽位遮罩或内边框。
5. 页面级边框，例如胶片尺孔。
6. 裁切辅助线。
7. 仅 UI 可见的选中框、拖拽手柄、提示层。

第 7 层默认不进入导出，除非明确属于导出选项。

## 测试要求

涉及尺寸和渲染的修改至少应覆盖：

- 固定页面尺寸下的导出像素尺寸测试。
- 二 / 四 / 九模板槽位数量和边界测试。
- 同一页面模型下预览与导出使用同源数据的测试。
- 边框叠加不改变照片槽位几何的测试。
- EXIF 方向样本测试。
