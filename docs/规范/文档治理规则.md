# 文档治理规则

## 一、目的与适用范围

本规则管理留素正式文档的类型、权威、生命周期、Git 边界、命名路由和结构演进。适用于 `docs/` 下的正式文档，以及根目录 `AGENTS.md`、`README.md` 中承载的文档职责。

本规则不规定具体功能如何实现，也不是动态项目状态表。功能合同、设计、任务状态和验证结论由各自的权威载体承担。

## 二、文档类型与生命周期

| 类型 | 职责 | 是否进入 Git | 更新时机 | 退出方式 |
| --- | --- | --- | --- | --- |
| 规范性文档 | 规定当前有效的工程或领域合同 | 是 | 合同变化时 | 由新规范替代；历史靠 Git，不在正文保留版本流水 |
| ADR 决策记录 | 记录重要选择、理由、代价和替代关系 | 是 | 作出或替代重要决策时 | 不静默改写；由新 Accepted ADR 明确替代并互相链接 |
| 设计文档 | 描述系统或功能如何组织、状态归谁负责 | 是（建立需所有者批准 + ADR） | 设计或实现边界变化时 | 失效后更新、删除或由新设计替代 |
| 实施计划 | 约束已批准复杂任务的范围和执行方式 | 活动期内 | 范围或方法变化时 | 完成后先提炼长期结论，再删除失效计划；不归档全量计划 |
| 动态任务状态 | 当前进度、阻塞、下一步 | 不进稳定文档；只进仓库 Issues | 状态实际变化时 | Issue 关闭后由关闭记录承担历史 |
| AI经验笔记 | 精选的可复用方法、失败经验 | 是 | 主题有新证据时原地更新 | 被推翻时更新或退出索引；不按会话日期新建副本 |
| 临时研究材料 | 搜索笔记、假设、未整理分析 | 否 | 调查期间按需 | 结论提炼进正式文档后删除 |
| 自动生成报告 | 测试、审计、测量工具输出 | 否 | 每次重新生成 | 到期删除或本地清理，不进默认路由 |

## 三、唯一事实原则

- 同一动态事实只能有一个权威载体；仓库 Issues 是任务动态状态的唯一权威。
- 规范、决策、计划和经验笔记不复制 Issue 的当前进度、阻塞或下一步；需要关联时只引用。
- 当前规范只描述现行合同，不保存版本流水。
- 历史优先依赖 Git 提交、已关闭 Issue 和 ADR；不建立第二套历史账本。
- 测试通过、审计通过、文档完成不自动等于用户验收；用户验收只来自所有者明确裁定。

## 四、Git 与本地边界

进入 Git 的内容：

- 根 `AGENTS.md`、根 `README.md`；
- `docs/` 下的规范、决策、经验笔记，以及活动期内已批准的实施计划；
- 后续的源码、测试、构建脚本和工程配置。

不进入 Git、本地保留的内容：

- `references/`：旧留素项目只读参考，已加入 `.gitignore`。原件不改写；只用于查旧行为、旧算法、旧 UI 反例和旧踩坑。禁止未经审查直接复制旧代码，禁止把旧项目文档或临时补丁逻辑原样搬入新项目，禁止因旧项目“能运行”就忽略本仓库现行规则。
- 原始日志、构建输出、导出样张原始件、截图录屏等原始证据。
- Agent 缓存、临时分析和未整理材料。

若原始证据的结论需要长期使用，把足以支持结论的脱敏摘要写进正式文档，原始件留本地。

## 五、命名与路由

- 根目录名 `docs` 保持英文；`docs` 下的目录与文档名使用中文。
- `README.md`、`AGENTS.md`、ADR 编号等工具惯例可保留英文。
- `docs/README.md` 只列出实际存在的分类和路由，不把尚未创建的目录写成既成结构。
- 正式文档不保留“最后人工/AI 更新”页眉；变更时间线由 Git 承担。

## 六、计划与动态状态

- 简单任务不创建计划文档。
- 复杂任务经所有者批准后建立计划文档；计划引用 Issue，但不复制 Issue 状态。
- 计划完成后，先把仍然有效的合同、设计决定和验证结论提炼进规范或决策，再删除失效计划。
- 不建立全量历史计划归档；只有确有长期参考价值的材料，才通过单独决定保留。

## 七、验证与证据

- 本地检查只证明所检查的文件、配置或本地行为；自动测试只证明其断言和运行环境覆盖的范围。
- 实机验证只证明对应机器与场景；用户验收只来自所有者的明确裁定。
- 任一证据不得被解释为超出其版本、环境和验证范围的结论。

## 八、结构演进

- 新增、删除、合并或重命名 `docs/` 一级目录，必须经所有者批准并以新 ADR 记录。
- 当前结构不是永久结构；事实证明更合适的组织方式时，受控调整。
- 不因“未来可能有用”或追求目录对称而预建目录或空文件。
- 结构调整须在同一提交中更新全部受影响链接与 `docs/README.md`；根路由职责变化时同步更新 `AGENTS.md`。
- 不保留层层重定向的占位文件。当前结构的决定见 [ADR-0002](../决策/ADR-0002-文档体系迁移与R式治理.md)。

## 九、禁止的失控模式

禁止：

- 建立更新记录目录或文档更改历史目录；
- 建立全局动态状态账本；
- 为每个内部步骤创建 Markdown 记录；
- 在稳定文档中累积版本流水；
- 让历史计划或废弃入口继续进入默认读取路由；
- 为管理文档再建立大型审计系统；
- 因未来可能使用而预建目录。
