# 02-领域模型与项目文件

开始前必须先读取同目录的 [00-基准.md](00-基准.md)。本会话只执行本子方案，不外扩到其它子方案。

## 承接状态

- 前面已经完成：01 骨架可构建、测试可跑。
- 本方案负责：不依赖任何 UI 的领域模型层与项目文件序列化。
- 后续计划：完成后交给 [03-图片导入与缓存](03-图片导入与缓存.md)。

## 当前范围

- 页面档案：物理尺寸 mm、归一化/像素坐标换算入口（统一函数，[尺寸与渲染规则](../../规范/尺寸与渲染规则.md)）。
- 打印机档案：名称、可打印区域、留白、推荐输出密度；小米 1S 首档案（可打印区域按整页近似占位，数据来源标注"待核定"）。
- 通用布局模型：槽位矩形列表（归一化），无预设数量硬编码（[ADR-0006](../../决策/ADR-0006-产品定位与布局泛化.md)）；预设生成器：单张全幅 / 二 / 四 / 九，具体几何参照旧版行为与实物比例确定。
- 槽位图片状态：路径、旋转、镜像、填充模式、裁切偏移、缺失/失败状态（[图片与缓存规则](../../规范/图片与缓存规则.md)）。
- 页面背景（纯色）。
- 项目文件 JSON 序列化 / 反序列化 + 版本字段。
- 上述全部的单元测试（含往返序列化、预设几何边界、非法输入拒绝）。

## 明确不做

- 图片实际解码、渲染、缓存实现。
- 校准偏移的 UI 与计算（模型字段可预留，标注"未实施"）。
- 边框模型。

## 实施步骤

1. 定义档案、布局、槽位、页面模型的头文件与不变量注释（重点注释位置见[工程规则](../../规范/工程规则.md)注释底线）。
2. 实现预设生成器与坐标换算，先写测试再实现。
3. 实现 JSON 序列化与版本字段，往返测试。
4. 全量测试 + 构建，提交 Git。

## 验收

- 单元测试通过：坐标换算、四类预设几何、序列化往返、损坏 JSON 拒绝。
- 模型层零依赖 Qt Quick / UI 头文件（代码审查确认）。
- 提交说明含测试命令与结果。
