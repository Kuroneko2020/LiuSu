# 01-项目骨架与构建基线

开始前必须先读取同目录的 [00-基准.md](00-基准.md)。本会话只执行本子方案，不外扩到其它子方案。

## 承接状态

- 前面已经完成：无（首个子方案）。
- 本方案负责：建立可构建、可运行、可测试的项目骨架。
- 后续计划：完成后交给 [02-领域模型与项目文件](02-领域模型与项目文件.md)。

## 当前范围

- CMake 工程 + Qt 6 (QML) 应用壳：一个空主窗口能启动。
- 目录结构按[工程规则](../../规范/工程规则.md)职责分层：`src/domain`、`src/services`、`src/app`、`qml/`、`tests/`（具体命名可在实施时微调，但分层职责不得合并）。
- 测试框架接入（Qt Test 或 Catch2，实施时定并在注释说明理由），至少一条能跑通的示例测试。
- `.gitignore` 核对构建产物不被跟踪。
- 构建说明写入根 README 或 `docs/`（一条命令可构建）。

## 明确不做

- 任何业务模型、UI 页面、图片处理。
- 不引入超出 Qt 必要项的第三方依赖。

## 实施步骤

1. 确认本机 Qt 6 / CMake 工具链版本，版本号写入构建说明。
2. 建立 CMake 工程与应用壳。
3. 接入测试框架，写通示例测试。
4. 本地构建 + 运行 + 测试，记录命令与结果。

## 验收

- 构建命令一次成功，生成可执行文件并能启动空窗口。
- 测试命令一次通过。
- 提交 Git，提交说明含构建命令与结果。

## 验收后

更新 Issue #1 进度，转交 02。
