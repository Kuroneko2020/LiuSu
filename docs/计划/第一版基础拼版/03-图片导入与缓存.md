# 03-图片导入与缓存

开始前必须先读取同目录的 [00-基准.md](00-基准.md)。本会话只执行本子方案，不外扩到其它子方案。

## 承接状态

- 前面已经完成：02 领域模型与项目文件（含槽位图片状态定义）。
- 本方案负责：图片读取、EXIF 方向、缩略图与缓存服务。
- 后续计划：完成后交给 [04-渲染管线与样张](04-渲染管线与样张.md)。

## 当前范围

- 统一图片读取入口：EXIF 方向统一处理，预览/缩略图/导出共用（[图片与缓存规则](../../../规范/图片与缓存规则.md)）。
- 原图信息缓存：尺寸、EXIF 方向、可读性。
- 缩略图缓存：磁盘 + 内存两级，受 `previewMaxEdge` 约束。
- 缓存 key：按规则完整实现（路径/身份/参数/算法版本），key 组成写关键注释。
- 失效策略：文件变化、参数变化、算法版本变化时失效。
- 缓存目录管理：位置可配置，清理不触碰用户原图与项目文件。
- 测试：同路径替换、方向样本（含 90/180/270 与镜像 EXIF）、失效触发、清理边界。

## 明确不做

- 页面级合成渲染（下一子方案）。
- 槽位级旋转/镜像/裁切的应用渲染（属渲染管线，本方案只保证读取与方向正确）。
- UI。

## 实施步骤

1. 造固定测试图片集：不同方向 EXIF 的 JPEG/PNG，放入测试资源。
2. 实现统一读取入口与原图信息缓存，测试先行。
3. 实现缩略图缓存与 key，测试 key 各组成部分单独变化均导致失效。
4. 全量测试 + 构建，提交 Git。

## 验收

- 方向样本测试：读取结果方向全部正确。
- 同路径替换图片测试：不命中旧缓存。
- 测试后磁盘缓存可整体删除且不报错、不误删用户文件。
