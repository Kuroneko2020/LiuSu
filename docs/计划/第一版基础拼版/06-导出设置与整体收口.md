# 06-导出设置与整体收口

开始前必须先读取同目录的 [00-基准.md](00-基准.md)。本会话只执行本子方案，不外扩到其它子方案。

## 承接状态

- 前面已经完成：05 界面实现，全流程可走通。
- 本方案负责：导出设置完善、项目文件串通、整体验证与收口。
- 后续计划：完成后第一阶段收口，计划目录按[文档治理规则](../../规范/文档治理规则.md)处理（先提炼长期结论，再删除失效计划）。

## 当前范围

- 导出：档位 PPI / 自定义、JPEG 质量、PNG、原图导出模式、命名规则、默认路径记忆。
- 项目保存 / 打开：界面入口、版本兼容（旧版本文件拒绝或迁移）、最近项目。
- 缓存设置：目录、清理入口。
- 健壮性：缺失图片文件的项目打开行为（占位与可解释错误，不静默空白导出）。
- 整体验证：按 [00-基准](00-基准.md) 最终验收口径逐条执行。
- 收口：提炼长期结论（如有）进规范/经验笔记，更新 Issue #1，计划收尾。

## 明确不做

- 新功能（发现的问题只修不扩）。
- 边框、校准、直连打印（未来方向）。

## 实施步骤

1. 导出设置项接入与测试（含边界：极低 PPI、超大导出提醒）。
2. 项目打开健壮性测试（缺图、损坏文件、旧版本字段）。
3. 按 00-基准验收口径执行全流程实测，记录结果。
4. 用小米 1S 实际打印样张，所有者裁切验收。
5. 收口提交与 Issue 更新。

## 验收

- 00-基准最终验收口径 1–5 全部通过（含所有者实机打印验收）。
- 全部测试通过；构建干净。
- 收尾说明：改了什么、验证了什么、剩余风险。
