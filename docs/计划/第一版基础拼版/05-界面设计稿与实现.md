# 05-界面设计稿与实现

开始前必须先读取同目录的 [00-基准.md](00-基准.md)。本会话只执行本子方案，不外扩到其它子方案。

设计稿选定环节从子方案 02 起即可并行推进；QML 实现部分依赖 04 完成。

## 承接状态

- 前面已经完成：04 渲染管线与样张（界面对接的几何事实已验证）。
- 本方案负责：视觉风格稿选定 + QML 界面实现与绑定。
- 后续计划：完成后交给 [06-导出设置与整体收口](06-导出设置与整体收口.md)。

## 当前范围

### 设计稿（先行）

- 2–3 版风格稿：整体布局密度、配色、控件形态、动效倾向（目标：干净、丝滑、灵动、高级，[ADR-0007](../../决策/ADR-0007-技术栈与界面方向.md)）。
- 所有者选定一版后作为过程草稿留档；界面验收口径按 [ADR-0011](../../决策/ADR-0011-美术效仿对象与验收口径.md)：RhineLabUI 效仿方向 + [界面设计基准](../../设计/界面设计基准.md)参数，所有者最终裁定。

### QML 实现（选定后）

- 页面结构：导入区、布局选择（首批四预设）、槽位编辑（旋转/镜像/填充/裁切偏移/替换/清除）、背景色、导出设置（档位 PPI、格式、质量、路径）。
- 预览显示：绑定渲染管线输出，缩放平移不改变导出几何。
- 单向状态流：UI 命令 → 应用服务 → 领域模型 → 渲染/缓存失效 → UI 刷新（[UI规则](../../规范/UI规则.md)）。
- 视觉与动效按[界面设计基准](../../设计/界面设计基准.md)实现（效仿对象 RhineLabUI，见 [ADR-0011](../../决策/ADR-0011-美术效仿对象与验收口径.md)）；QML 只做展示与交互，不承载几何真相。

## 明确不做

- 边框 UI、校准 UI。
- 自定义布局编辑器。
- 设置页的完整化（仅第一版必要项：缓存目录、默认导出路径等）。

## 实施步骤

1. 产出风格稿（静态图即可），提交所有者选定，结果记录进本文件。
2. 搭 QML 页面骨架与导航。
3. 逐区接入应用服务：导入 → 布局 → 槽位编辑 → 预览 → 导出设置。
4. 按风格稿打磨间距、配色、动效。
5. 全量测试 + 构建 + 实际点检，提交 Git。

## 验收

- 从导入到导出的全流程可在界面完成，结果与渲染管线直测一致。
- 界面观感符合 RhineLabUI 效仿方向 + 界面设计基准参数（[ADR-0011](../../决策/ADR-0011-美术效仿对象与验收口径.md)，所有者验收）。
- UI 层不出现尺寸换算、缓存 key、导出像素计算（代码审查确认）。
