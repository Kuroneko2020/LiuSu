# 第一版基础拼版：00-基准

状态：已批准（[ADR-0008](../../决策/ADR-0008-第一阶段实施细节与开发顺序.md)）。动态进度查[总跟踪 Issue #1](https://github.com/Kuroneko2020/LiuSu/issues/1)，本目录不复制 Issue 状态。

开始任何子方案前必须先读本文件。每个子方案会话只执行该子方案，不外扩。

## 所有者目标与最新取舍

把照片导入，提供拼版布局、边框与裁切，产出可打印的页面（[ADR-0006](../../决策/ADR-0006-产品定位与布局泛化.md)）。第一版交付一个能真实用于小米米家照片打印机 1S + 6 寸相纸的拼版导出工具。

关键取舍：

- 尺寸档案化不写死；打印机档案 + 校准偏移预留（[ADR-0003](../../决策/ADR-0003-页面与打印机档案化.md)）。
- PPI 多档位：300 / 600 / 自定义（72–1200），默认 300；仅导出不直连（[ADR-0004](../../决策/ADR-0004-导出PPI多档位与仅导出.md)）。
- 边框系统延后，架构预留（[ADR-0005](../../决策/ADR-0005-第一阶段范围调整.md)）。
- 布局泛化：通用槽位布局模型，首批预设单张全幅 / 二 / 四 / 九（[ADR-0006](../../决策/ADR-0006-产品定位与布局泛化.md)）。
- 技术栈 Qt 6 + C++17 + QML；设计稿先行（[ADR-0007](../../决策/ADR-0007-技术栈与界面方向.md)）。
- 背景：首版纯色，默认白。导出格式：JPEG（质量可调）/ PNG + 原图导出模式。

## 范围

- 页面档案与打印机档案模型（6 寸 + 小米 1S 为首档案；可打印区域数值待官方手册或实测核定，先按 100×148mm 整页近似，核定后改档案数据）。
- 通用布局模型 + 首批预设：单张全幅、二（60×90 竖照双联）、四（66×44）、九（48×32）——几何沿用旧版验证值（[ADR-0010](../../决策/ADR-0010-横版页面与多页队列.md)）。
- 页队列：多页连续排版（底部胶片栏），整队导出。
- 图片导入、EXIF 方向、缩略图、缓存。
- 槽位编辑：旋转、镜像、填充模式、裁切偏移、替换。
- 纯色背景；预览；多档位 PPI 导出（JPEG/PNG）。
- 项目保存 / 打开（JSON）。
- 单元测试 + 固定输入导出样张。
- 界面：设计稿选定后实现（导入、布局、槽位编辑、导出设置）。

## 明确不做

- 边框系统与胶片尺孔（渲染顺序预留层级即可）。
- 校准功能的 UI 与计算（模型留输入位）。
- 打印机直连、修图、云同步、多页文档、自定义布局编辑器。
- 花纹背景、贴纸、文字。

## 必须保护的底线

- 预览、缩略图、导出共享同一套页面几何与渲染管线（[尺寸与渲染规则](../../规范/尺寸与渲染规则.md)）。
- 缓存 key 完整性（[图片与缓存规则](../../规范/图片与缓存规则.md)）。
- QML 不是几何真相来源（[UI规则](../../规范/UI规则.md)）。
- 五个工程底线（[工程规则](../../规范/工程规则.md)）。

## 最终验收口径

1. 导入 4 张不同 EXIF 方向的照片，选四宫格，逐槽位旋转/镜像/裁切偏移，导出 300 PPI JPEG；用小米 1S 打印并裁切，得到 4 张与预览一致的横照（每张 66×44mm）。
2. 同一项目文件重开后导出，像素级与关闭前一致。
3. 预览缩放窗口、切换模板、切换 PPI 不改变导出几何。
4. 全部单元测试与样张测试通过；样张人工目检无明显问题。
5. 界面达到选定风格稿的观感标准（所有者验收）。
