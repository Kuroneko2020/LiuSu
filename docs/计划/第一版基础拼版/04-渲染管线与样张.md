# 04-渲染管线与样张

开始前必须先读取同目录的 [00-基准.md](00-基准.md)。本会话只执行本子方案，不外扩到其它子方案。

## 承接状态

- 前面已经完成：02 领域模型、03 图片读取与缓存。
- 本方案负责：预览、缩略图、导出共用的页面渲染管线（无界面）。
- 后续计划：完成后交给 [05-界面设计稿与实现](05-界面设计稿与实现.md)。

## 当前范围

- 共用渲染入口：输入页面模型 + 图片服务，输出 QImage；预览与导出只有分辨率参数不同（[尺寸与渲染规则](../../规范/尺寸与渲染规则.md)渲染同源）。
- 槽位渲染：填充模式（完整放入/填充裁切）、旋转、镜像、裁切偏移的几何实现，顺序写关键注释。
- 绘制顺序：背景 → 槽位占位 → 槽位图片 →（预留边框层注释）→ UI 专属层不进导出。
- 纯色背景渲染。
- 导出像素计算：物理尺寸 × PPI（多档位）。
- 固定样张测试：固定测试图片 + 固定项目 → 输出与基准像素尺寸、几何断言比对；四类布局各出一张样张。
- 性能基线：单页预览渲染耗时的简单测量（不设硬指标，建立可比基线）。

## 明确不做

- QML 预览显示（05 承担）。
- 边框绘制（只留层级注释占位）。
- 校准偏移应用（预留输入位）。

## 实施步骤

1. 实现渲染入口与槽位几何变换，先写几何断言测试。
2. 实现导出像素计算与多档位 PPI，测试 300/600/自定义三档输出尺寸。
3. 生成固定样张（测试资源 + 断言），提交样张生成说明。
4. 全量测试 + 构建，提交 Git。

## 验收

- 同一页面模型在预览与导出路径产出的几何一致（同源测试）。
- 样张测试通过：槽位数量、位置、方向、背景正确。
- 窗口无关性：渲染入口不引用任何屏幕/QML 尺寸（代码审查确认）。
