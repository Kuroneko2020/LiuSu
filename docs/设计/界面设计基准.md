# 界面设计基准：照片工作台

本基准描述当前界面的设计组织与实现合同。逐页模板依据 [ADR-0013](../决策/ADR-0013-照片工作台与逐页模板.md)，空间互动与开放目录依据 [ADR-0014](../决策/ADR-0014-空间交互与可扩展目录.md)。主要美术效仿对象为只读 `references/RhineLabUI/`，重点是实体、深度、惯性与响应。新界面的观感是否达到要求，由所有者验收裁定，动态状态查[总跟踪 Issue](https://github.com/Kuroneko2020/LiuSu/issues/1)。

## 一、视觉判断

界面以照片和纸面为主体。模板是放置在空间中的实体板，台面阴影、板面厚度、透视和反光分别响应；进入编辑与换页时相纸从倾转状态落定。工具和页卡采用较小力度的空间反馈。共同顶栏、字号和留白维持同一工作空间。

- 提取 RhineLabUI 的空间秩序、实体响应与落定感，颜色和细线只承担辅助组织。
- 不再要求每个控件有螺丝、透明罩、挤出边或按压缩放。照片保持清晰，编辑预览不叠奶雾。
- 信号色用于当前选中、主操作线索、焦点；红色只用于删除或错误。
- 模板入口始终可见，不把核心操作藏在悬停状态。

## 三、页面组织

### 模板首页

共同顶栏包含品牌、照片拼版入口、打开项目。模板库可搜索名称、分类及说明，横向滚动按需生成卡片；当前四个基础模板只是目录起点。展示板使用照片素材展示布局，底部持续显示选择模板。已进入编辑后可以继续当前项目；回到模板首页再选模板，是更换当前页模板。另开项目通过明确的新项目入口进行。

展示板有轻微错角，指针靠近时抬起 36px，随位置最多绕纵轴倾转 22°、横轴倾转约 14°，按下回落至 3px；SpringAnimation 带阻尼趋于目标。投影留在台面并独立位移、缩放，板面反光随角度变化。预览随可用卡片高度缩放，保持页面比例，不能与名称重叠；按钮命中区域留在外层，避免板面追随鼠标产生焦点抖动。

### 编辑工作台

- 中央：正视相纸、当前页名称、导入照片与添加页面。
- 右侧：可滚动检查栏，依次为当前页模板、所选照片、项目背景、导出设置。
- 底部：可横向滚动页队列，各页缩略图显示页码与模板名。长队列由 ListView 按需生成。
- 共同顶栏：新项目、打开、保存、导出照片。顶栏导出入口将检查栏滚到导出区，窄窗口下仍可达。
- 初始窗口按屏幕逻辑可用区限制，最大 1440×920；最小 960×640 与屏幕可用区取小。高 DPI 不使用物理分辨率硬编码。

检查栏只在选中照片时展开照片操作。当前模板入口打开可搜索、按需生成的模板库，避免模板增多后挤占全部检查栏。进入另一页时回到检查栏顶部。原生文件、目录与颜色选择器负责本地路径选择；添加、删除与替换项目提示使用同一控件语言的中文按钮。

## 四、操作与状态

1. 选择模板进入工作台。点击空槽可添加照片；批量导入从当前页往后填空位，满了继续新页。
2. 点击已有照片选中，右侧显示旋转、镜像、替换、移除、完整显示/铺满裁切。拖动照片取景；滑块精确调整，支持复位；双击可替换。
3. 每页独立换模板。对应槽位状态保留，缩减后多余照片及编辑状态进入紧邻新页；其他原有页面保持。
4. 添加页面同时选择初始模板和页数，支持一次创建十页或更多（上限每次 100）。
5. 背景及导出设置为项目级。导出控件由能力定义生成，当前支持格式选择、PPI 整数及 JPEG 质量；类型、范围、预设、条件显示与高级设置均来自定义，不在 QML 固定清单。未来新增能力先实现服务、保存和测试，再注册定义。
6. 新项目或打开其他项目替换已有内容前提示保存；删页前确认，至少保留一页。取消选择器不发命令。
7. 保存/打开使用 v1 项目格式，页面可选保存模板 ID，实际几何独立保存；缺失目录仍可重开和导出，旧项目仍可读取。批量输出遇到同名成品自动换整批前缀，不静默覆盖；失败报告已完成页数。

## 五、材质与动效

- 柔影共用 `GradientShadow.qml`，使用单层渐变体与 MultiEffect 柔化；隐藏效果输入，避免叠印。
- 空间主体共用 `SpatialSurface.qml`，展示板高力度，页卡小力度（倾转 8°、抬起 7px）。工具按钮悬停上移 2px、按下下移 2px，保留键盘焦点。
- 选择框直切杏金描边；它与拖放高亮、按钮、影子均为 UI 装饰，不写入导出。
- 纸面进场与换页 420ms 从倾转状态落定，按下照片立即结束过渡，使用台面坐标计算裁切增量。照片不叠反光或透明雾层。裁切合并为 32ms 更新，松手提交最终值。
- 静止时没有持续动画或计时器；不为每次指针位移重新解码照片、生成预览或计算导出。

## 六、实现职责

| 组件 | 职责 |
| --- | --- |
| `WorkspaceHeader` | 共同导航与项目操作 |
| `StudioButton` / `LineIcon` / `SectionLabel` | 工具控件、统一线图标与微标注 |
| `LayoutBoard` / `TemplateMini` / `TemplatePicker` | 模板展示与当前页模板入口 |
| `SpatialSurface` | 展示实体、厚度、反光、独立投影与阻尼运动 |
| `ExportSettingsPanel` / `ExportOptionControl` | 能力定义驱动的导出控件 |
| `PageCanvas` | 预览、选中、照片拖放与取景输入 |
| `EditorInspector` | 照片/背景/导出设置 |
| `PageQueue` | 页面导航与队列缩略图 |
| `EditorPage` / `Main` | 页面组合及选择器、确认对话框 |
| `AppController` | 项目状态、命令及通知 |
| `domain::PageOperations` | 换模板保全照片状态 |
| `domain::TemplateCatalog` / `services::TemplateLibrary` | 目录元数据、校验、导入及持久化 |
| `domain::ExportOptions` | 当前输出能力定义与参数校验 |
| `PageRenderer` | 共享页面像素与占位表达 |

模板小预览只读取领域槽位，不反写坐标。正式预览与导出经过同一渲染器，物理尺寸、EXIF、裁切算法和缓存契约仍按对应规范。页索引发生插入/删除时更换全局缓存代次；单页照片调整仅失效该页。

空槽和读取失败提示继续使用共享渲染管线，保留预览/导出一致性。空槽降低装饰权重；错误仍可解释，不能静默导出空白。
