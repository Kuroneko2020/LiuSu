# 界面设计基准（亚克力展示板体系）

状态：现行有效。设计语言经 [ADR-0009](../决策/ADR-0009-界面设计语言亚克力展示板.md) 确定，验收参照为 `设计稿-J/`（J 稿 HTML 与截图，随仓库入库）。

## 一、设计理念

**每一页照片都装裱在一块乳白亚克力展示板后。** 板是奶白半透明的，四角有金属螺丝固定，能看见板缘的厚度和斜面反光；照片衬在玻璃后微微发雾；整块板浮起，有投影。

- 隐喻来源：所有者提供的亚克力展示框参照图 + [RhineLabUI](https://github.com/LBEILC/RhineLabUI)（莱茵生命 PV 终端复刻）的设计理念：暖灰白底、近黑文字、唯一暖杏金信号色、细线紧凑排字、精密克制的动效。
- 该隐喻同时是产品语义：留素 = 照片装裱、展示、裁切。
- 全应用统一：主页、编辑页、设置、弹窗、每个控件都是同一套材质的不同厚度与透明度，不允许出现体系外的平面样式。

## 二、色彩

| 用途 | 值 |
| --- | --- |
| 环境底色（亮/暗） | `#edeae4` / `#e0dcd2`，165° 渐变 |
| 画布台面 | `#dcd7cb`（叠 38px 细网格 rgba(28,25,18,.04)） |
| 主文字 | `#1c1a16` |
| 次级 / 弱文字 | `#6f6a60` / `#a39c8e` |
| 信号色（唯一强调色） | 琥珀 `#d98e2b`；深 `#b97517`；软底 `rgba(217,142,43,.16)` |
| 空槽斜纹 | 45° 重复条纹 rgba(28,25,18,.055) |
| 危险 | `#b3402e`（仅悬停态） |

除信号色外不引入第二强调色。

## 三、字体与排字

- 字体：**MiSans**（小米官方字体，免费商用，随应用打包）；回退 Segoe UI / 微软雅黑。字重 300/400/600/700。
- 数字用等宽数字（tabular-nums）。
- 微标注体系：小型双语标签（如 `BACKGROUND 背景`、`FILMSTRIP 页队列`），英文 10.5px、字距 2.2px、弱色；中文 12.5px、字距 1px。
- 档案编号：布局 `LY-01…`、页面 `PG-001…`，等宽字距 1.8px。

## 四、亚克力材质规格

板体基底（158° 渐变）：

```text
linear-gradient(158deg,
  rgba(253,253,251,.80) 0%,
  rgba(248,247,243,.62) 42%,
  rgba(244,243,238,.58) 100%)
backdrop-filter: blur(3–5px) saturate(1.05)
border: 1px solid rgba(255,255,255,.95)
```

厚度与光（box-shadow 组合，顺序固定）：

```text
inset 0 0 0 2px rgba(255,255,255,.42)     内包边
inset 3px 3px 12px rgba(255,255,255,.55)  内斜面反光
3px 4px 0 -1px #e9e6de                    挤出板缘（亮侧）
4px 5px 0 -1px #c9c5b9                    挤出板缘（暗侧）
0 16px 38px rgba(28,25,18,.15)            落影
```

斜面反光（sheen）：118° 线性渐变，两端亮带 `rgba(255,255,255,.42→.34)`，中部基本透明。

四角螺丝：距角 8px，直径约 5.5px——中心白点 + 灰环 `#b5b1a7`，带 1px 投影。四板角各一。

照片衬于板后：照片层与板层分离（照片在低 z 层），玻璃后照片加奶雾 `rgba(250,250,248,.06–.24)` 渐变，保持清晰可辨。

## 五、透明度分级

同一块"亚克力"，按层级只用四种厚度（g1 最实 → g4 最透）：

| 级 | 部件 | 基底透明度 |
| --- | --- | --- |
| g1 | 顶栏 | .92 → .78 |
| g2 | 背景栏 / 胶片栏 / 设置卡 | .70 → .50 |
| g3 | 次级按钮 / 输入 | .55 → .38 |
| g4 | 弹窗底衬（磨砂整层） | .28 + 全屏 blur 8px |

弹窗本体是最厚的板（.96 → .88 + 24px blur），且带侧缘厚度。

## 六、组件规格

- **按钮（亚克力块）**：高 36px，g2/g3 材质；悬停上浮 2px，按压 scale .96。
- **主按钮（黑）**：近黑底 `#1c1a16` + 米白字 + 6px 琥珀 tick；板缘挤出阴影同材质。
- **分段选择器**：细线框 + 选中段黑底米白字。
- **色板**：22px 方块，玻璃顶缘高光；选中态琥珀 outline。
- **槽位工具板**：浮于纸面（translateZ），亚克力小板带螺丝；图标悬停变琥珀底。
- **胶片栏**：g2 亚克力长条；页卡 148:100 缩略 + 底部 PG 编号黑条；选中页琥珀描边 + 左侧琥珀条。
- **吐司**：g1 亚克力 + 左缘 3px 琥珀 + 圆形琥珀勾。
- **弹窗**：g 最厚亚克力 + 螺丝 + 侧缘；出现时背后整层磨砂（g4）。

## 七、动效参数

| 交互 | 参数 |
| --- | --- |
| 悬停浮起 | translateY(-2~-6px)，200–300ms，cubic-bezier(.25,.9,.3,1) |
| 按压 | scale(.96)，150ms |
| 弹窗出现 | 背景磨砂淡入 + 面板上浮，250ms |
| 页面切换（主页↔编辑） | 3D 交叉过渡：旧页后退下沉、新页前浮，300ms |
| 选中信号 | 琥珀 outline 直切 + 下划线 180ms；呼吸类动画仅用于页面悬浮 |
| 布局切换 | 槽位照片平滑重排 250ms |

禁止弹跳/回弹类夸张动效；一切运动服从"精密仪器"的手感。

## 八、几何常量

- 页面：**148×100mm 横版**（宽高比 1.48）。
- 预设几何（归一化 = mm/148 或 mm/100，源自旧版 `TemplateLayout.cpp`）：
  - LY-01 单张全幅：整页；
  - LY-02 二宫格：`(7,5,60,90)` `(81,5,60,90)`——竖照双联；
  - LY-03 四宫格：`(4,3,66,44)` `(78,3,66,44)` `(4,53,66,44)` `(78,53,66,44)`；
  - LY-04 九宫格：x ∈ {0.667, 50, 99.333}、y ∈ {0.667, 34, 67.333}、槽 48×32。

## 九、QML 实现映射

- 亚克力板：`MultiEffect`（blur + saturation）+ 分层 Rectangle（基底/高光/板缘）；板缘与螺丝可用 9-patch 图或 Canvas 自绘。
- 照片衬玻璃后：照片层与玻璃层分离，玻璃层 blur 作用于下层。
- 动效：`Behavior` + `NumberAnimation`（表七参数）；页面切换用 `StackView` + 自定义过渡。
- 设计稿为静态示意，实现以本基准参数为准，动效逐项核对。
