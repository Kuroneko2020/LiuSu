# 界面设计基准：照片工作台

本基准描述现行视觉与交互原则，不固定最终界面分区。美术方向依据 [ADR-0015](../决策/ADR-0015-克制材质与稳定内容.md)，逐页模板依据 [ADR-0013](../决策/ADR-0013-照片工作台与逐页模板.md)，目录与导出扩展依据 [ADR-0014](../决策/ADR-0014-空间交互与可扩展目录.md) 中继续有效的合同。RhineLabUI 仅为局部材质、光感与运动品质参考。观感由所有者验收裁定，运行证据与动态状态查[总跟踪 Issue](https://github.com/Kuroneko2020/LiuSu/issues/1)。

## 一、视觉判断

界面以照片和纸面为主体。薄而明确的厚度、半透明硬质材料、克制边缘高光与柔和投影构成静态层次；不靠对象不断运动证明立体感。既不追求三维展示装置，也不退回纯色矩形加细描边的普通扁平卡片。

- 容器、导航、工具控件、选择器可承担材质与轻微光线反馈；不是每个对象都要独立玻璃外壳，避免层层套板。
- 照片、纸面及用于观察、比较、取景和精确操作的内容保持清楚、稳定。材质不蒙雾、不染色、不增加反光遮挡，不改变成品内容的呈现。
- 光线可以变化，操作位置与视觉内容不必移动。边缘高光、表面反射强弱和细微阴影变化可表达悬停、按下、选中。
- 厚度不等于厚重，玻璃不等于整屏泛白，高级不等于发光。避免夸张挤出边、多层重复阴影、强光晕和大范围扫光。
- 信号色用于当前选中、主操作线索、焦点；红色只用于删除或错误。
- 模板入口始终可见，不把核心操作藏在悬停状态。

## 二、颜色与排字

沿用当前浅色工作台作为近期调整基础；具体颜色、透明度与材质力度是待验证的实现选择，不在此锁死最终数值。主文字、次级说明、选中线索及错误提示应有可辨层级，半透明背景上的控件仍须清晰可读。

字体优先本机 MiSans，缺失时回退 Microsoft YaHei UI。主要操作名称用中文；短英文微标注只作辅助，不让低对比小字承担关键操作。标题服务于使用入口，不作为宣传标语。

## 三、近期组织与内容职责

本节描述现有流程与本轮保留的能力，不规定最终导航、工具栏、检查面板、队列的位置。沿用当前基本组织，不借材质收敛全面重排信息架构。

### 模板首页

保留品牌、照片拼版入口、打开项目。模板库可搜索名称、分类及说明，横向滚动按需生成卡片；当前四个基础模板只是目录起点。模板预览与名称便于比较，选择入口持续可见。已进入编辑后可以继续当前项目；回到模板首页再选模板，是更换当前页模板。另开项目通过明确的新项目入口进行。

卡片是稳定可选择的模板入口。优先保留静态材质层次，以细微高光、描边和阴影反馈，去掉不必要的倾转、抬升、回弹。先判断问题来自运动、材质力度还是占用空间，再调整；不机械缩小卡片，不将搜索、滚动或目录扩展换成固定四项。预览保持页面比例，不与名称重叠。首页不以大幅标语、场景摄影背景或装饰留白撑起设计。

### 编辑工作台

- 编辑内容：正视相纸、清晰照片、当前页名称、导入照片与添加页面。
- 设置：当前页模板、所选照片、项目背景、导出设置可滚动访问，窄窗口下导出入口仍可达。
- 页面导航：可滚动、按需生成的页队列，缩略图显示页码与模板名；照片不随悬停倾转或抬升。
- 项目操作：新项目、打开、保存、导出照片。
- 窗口遵守屏幕逻辑可用区，高 DPI 不以物理分辨率硬编码。

选中照片后展示照片操作。当前模板入口打开可搜索、按需生成的模板库，避免模板增多后挤占全部设置空间。原生文件、目录与颜色选择器负责本地选择；添加、删除与替换项目提示使用同一控件语言的中文按钮。

## 四、操作与状态

1. 选择模板进入工作台。点击空槽可添加照片；批量导入从当前页往后填空位，满了继续新页。
2. 点击已有照片选中，右侧显示旋转、镜像、替换、移除、完整显示/铺满裁切。拖动照片取景；滑块精确调整，支持复位；双击可替换。
3. 每页独立换模板。对应槽位状态保留，缩减后多余照片及编辑状态进入紧邻新页；其他原有页面保持。
4. 添加页面同时选择初始模板和页数，支持一次创建十页或更多（上限每次 100）。
5. 背景及导出设置为项目级。导出控件由能力定义生成，当前支持格式选择、PPI 整数及 JPEG 质量；类型、范围、预设、条件显示与高级设置均来自定义，不在 QML 固定清单。未来新增能力先实现服务、保存和测试，再注册定义。
6. 新项目或打开其他项目替换已有内容前提示保存；删页前确认，至少保留一页。取消选择器不发命令。
7. 保存/打开使用 v1 项目格式，页面可选保存模板 ID，实际几何独立保存；缺失目录仍可重开和导出，旧项目仍可读取。批量输出遇到同名成品自动换整批前缀，不静默覆盖；失败报告已完成页数。

## 五、材质与动效

- 柔影共用 `GradientShadow.qml`，使用单层渐变体与 MultiEffect 柔化；隐藏效果输入，避免叠印。
- `SpatialSurface.qml` 承载卡片静态薄边、半透明表面与局部光线反馈；照片和文字位于装饰层之上，不靠移动内容表达材质。键盘焦点与按下状态仍可识别。
- 选择框直切杏金描边；它与拖放高亮、按钮、影子均为 UI 装饰，不写入导出。
- 编辑纸面及照片在指针进入、停留、移动、离开和经过边缘时，位置、尺寸、朝向与视觉内容稳定；所有祖先容器都须满足这一点。进场、换页不添加装饰性变换或照片明暗过渡。主动拖动取景、旋转、换页等必要内容变化继续有效；裁切使用稳定台面坐标，合并高频更新，松手提交最终值。
- 允许视觉近似，不要求真实折射、完整三维建模或全控件玻璃化。技术应服务于观感、稳定与性能。
- 静止时没有持续动画或计时器；不为每次指针位移重新解码照片、生成预览或计算导出。

## 六、实现职责

| 组件 | 职责 |
| --- | --- |
| `WorkspaceHeader` | 共同导航与项目操作 |
| `StudioButton` / `LineIcon` / `SectionLabel` | 工具控件、统一线图标与微标注 |
| `LayoutBoard` / `TemplateMini` / `TemplatePicker` | 模板展示与当前页模板入口 |
| `SpatialSurface` | 卡片薄边、半透明层次、内容下方的光线与投影 |
| `ExportSettingsPanel` / `ExportOptionControl` | 能力定义驱动的导出控件 |
| `PageCanvas` | 预览、选中、照片拖放与取景输入 |
| `EditorInspector` | 照片/背景/导出设置 |
| `PageQueue` | 页面导航与队列缩略图 |
| `EditorPage` / `Main` | 页面组合及选择器、确认对话框 |
| `AppController` | 项目状态、命令及通知 |
| `domain::PageOperations` | 换模板保全照片状态 |
| `domain::TemplateCatalog` / `services::TemplateLibrary` | 目录元数据、校验、导入及持久化 |
| `domain::ExportOptions` | 当前输出能力定义与参数校验 |
| `PageRenderer` | 共享页面像素与占位表达 |

模板小预览只读取领域槽位，不反写坐标。正式预览与导出经过同一渲染器，物理尺寸、EXIF、裁切算法和缓存契约仍按对应规范。页索引发生插入/删除时更换全局缓存代次；单页照片调整仅失效该页。

空槽和读取失败提示继续使用共享渲染管线，保留预览/导出一致性。空槽降低装饰权重；错误仍可解释，不能静默导出空白。

## 七、素材与验收

`assets/photos/coast.png` 为通过 ImageGen 创建的原创演示素材，记录见同目录 `来源.md`；仅用于首页模板和开发演示，不自动写入用户新项目。不复制参考仓库代码或图像。

`references/RhineLabUI/` 与 CoreKeeper 层叠玻璃参照永久只读。RhineLabUI 只提供局部材质、光感与运动品质参考，不规定整体形态与交互。所有者近期附图也只作大致质感参考，不能据此引入布局或凭空出现的功能。J 稿和此前“已实现”截图是历史材料，不是现行定稿或验收证据。

验证应覆盖静止、悬停、快速进出、纸面与缩略图边缘经过，并检查选中、取景、换页、换模板、目录搜索/滚动及导出隔离。检查场景坐标与照片像素，不能仅断言本地 x/y 或命中框固定。既有项目、模板、缓存与导出回归继续适用。

可选 `LIUSU_REVIEW_DIR` 让 UI 集成测试生成实际 QML 渲染截图及运动帧。静态截图不能证明悬停稳定；自动测试和运行帧不能替代美术、桌面手感与实际打印验收。无法实机验证的部分明确列出，方向纠正和近期收敛不等于整套新美术定稿。
