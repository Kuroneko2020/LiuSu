## 查找事实

- 规则冲突、需求不明、需要扩大范围：停止并报告，不自行裁决。
- 历史与变更：Git 提交历史；文档体系结构变化见 [`决策/`](决策/)。
- `references/` 是被 Git 忽略的只读参考（外部美术参考：RhineLabUI 与《CoreKeeper 烹饪攻略 v4.3·层叠玻璃版》）；使用边界见[文档治理规则](规范/文档治理规则.md)。旧版留素快照已按 [ADR-0012](决策/ADR-0012-删除旧留素项目快照.md) 删除——因为想大幅度重构，防止受到旧版影响。

## 结构边界

- 普通任务不得自行新增、删除、重命名或重组 `docs/` 一级目录；调整需所有者批准并以 ADR 记录，见[文档治理规则](规范/文档治理规则.md)。
