# 留素文档入口

当前状态（2026-10-07）：尚无源码，处于第一阶段开发前阶段。第一阶段范围与产品取舍待确认清单见[根 README](../README.md)。文档体系已按 [ADR-0002](决策/ADR-0002-文档体系迁移与R式治理.md) 迁移为 Git 管理、按权威和生命周期组织的结构。

本文件只列出当前实际存在的正式文档分类和事实路由。

## 当前正式分类

- [`规范/`](规范/)：长期有效的项目规则。当前入口为[文档治理规则](规范/文档治理规则.md)、[工程规则](规范/工程规则.md)、[尺寸与渲染规则](规范/尺寸与渲染规则.md)、[边框与模板规则](规范/边框与模板规则.md)、[图片与缓存规则](规范/图片与缓存规则.md)、[UI规则](规范/UI规则.md)、[测试与交付规则](规范/测试与交付规则.md)。
- [`决策/`](决策/)：重要选择及其理由（ADR）。当前入口为 [ADR-0001：模板与边框分层](决策/ADR-0001-模板与边框分层.md)、[ADR-0002：文档体系迁移与 R 式治理](决策/ADR-0002-文档体系迁移与R式治理.md)。
- [`AI经验笔记/`](AI经验笔记/索引.md)：按主题整理的协作方法与经验，不具独立裁定权。当前入口为[索引](AI经验笔记/索引.md)。

`设计/`、`计划/` 等目录尚未建立：只在出现真实文档职责后，经所有者批准并通过 ADR 建立，不为未来用途预建空目录。

## 查找事实

- 规则冲突、需求不明、需要扩大范围：停止并报告，不自行裁决。
- 历史与变更：Git 提交历史；文档体系结构变化见 [`决策/`](决策/)。
- `references/` 是被 Git 忽略的只读旧版参考；使用边界见[文档治理规则](规范/文档治理规则.md)。

## 结构边界

- 普通任务不得自行新增、删除、重命名或重组 `docs/` 一级目录；调整需所有者批准并以 ADR 记录，见[文档治理规则](规范/文档治理规则.md)。
