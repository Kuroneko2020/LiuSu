# ADR-0006：产品定位与布局泛化

- 状态：Accepted
- 日期：2026-10-07

## 背景

所有者澄清产品本质：留素是把照片导入后，提供拼版布局、特定边框和裁切的软件——这至少是当前定位，且定位不固定。此前文档把模板限定为"二 / 四 / 九"模式，所有者明确指出这太狭隘。

"二 / 四 / 九"应是布局预设，而不是布局系统的边界。若把预设写进模型核心（如枚举、switch 分支），未来加"六张""自定义间距""竖排两张"等布局都要改核心代码，与产品定位不固定的方向冲突。

## 决策

1. 产品定位表述调整为：把照片导入，提供拼版布局、边框与裁切，产出可打印的页面。定位随需求演进，不写死。
2. 布局系统泛化：布局模型是"页面内的一组照片槽位矩形（归一化坐标）"，二 / 四 / 九只是生成该模型的首批预设，单张全幅同样是预设。模型核心不得出现预设数量的硬编码分支。
3. 未来布局扩展方向（预设生成器、自定义槽位、间距参数等）由布局模型的通用性承载，本 ADR 不预设具体形态，也不构成实现授权。
4. 边框属于产品核心能力之一（布局、边框、裁切三支柱），其实现延后是排期决定（[ADR-0005](ADR-0005-第一阶段范围调整.md)），不代表定位降级。
5. 本 ADR 有限替代 [ADR-0005](ADR-0005-第一阶段范围调整.md) 决策 3 中"二 / 四 / 九模板"的表述：第一阶段交付"通用布局模型 + 首批预设（单张全幅、二、四、九）"。

## 结果

好处：

- 模型一次做对，未来加布局形态只加预设，不动核心。
- 与"定位不固定"的产品方向一致，避免预设成为隐藏的产品边界。
- 单张全幅进入首批预设，覆盖 6 寸洗照最常见的整页输出。

代价：

- 布局模型比写死三档稍复杂，需要序列化与测试先行（由实施计划承担）。

## 被替代方式

若未来布局模型需要更 radically 不同的组织方式（如自由画布），应创建新的 Accepted ADR 替代本决策，并将本 ADR 状态改为 `Superseded`。
