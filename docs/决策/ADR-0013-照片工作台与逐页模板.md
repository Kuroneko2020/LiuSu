# ADR-0013：照片工作台与逐页模板

- 状态：Accepted
- 日期：2026-10-08
- 后续修正：[ADR-0014](ADR-0014-空间交互与可扩展目录.md) 将美术重点改为强空间互动，并开放模板目录、导出能力定义与可选页面模板身份；本决策的逐页操作与照片保全合同继续有效。

## 背景与授权

所有者认为原界面虽然有莱茵生命的感觉，但美术割裂、缺少高级感，明确授权大幅修改，并允许忽略此前已敲定的限制，前提是软件可用且操作符合产品定位。随后明确纠正模板限制：允许一次建立十个空页，各页使用不同模板，编辑中随时换模板，无须先导出。

## 决策

1. 主操作流保持选择模板、导入照片、调整排版、导出。主页与编辑页使用同一浅色照片工作台体系，具体组织见[界面设计基准](../设计/界面设计基准.md)。主要美术效仿对象仍为只读 `references/RhineLabUI/`，提取排字、留白、细线、有限信号色与主体层次。
2. 替代 [ADR-0009](ADR-0009-界面设计语言亚克力展示板.md) 的全控件亚克力、螺丝、奶雾、固定浮起等美术约束。立体感集中于照片模板展示和纸面；工具按钮以清晰、紧凑为先。旧定稿及 J 稿不限制此次重做。
3. 所有者本次直接授权实施，替代 [ADR-0007](ADR-0007-技术栈与界面方向.md) 与 [ADR-0011](ADR-0011-美术效仿对象与验收口径.md) 在本次任务上的逐稿选择审批要求。此授权不等于所有者已验收新界面；观感仍由所有者最终裁定。
4. 模板属于 `ProjectPage.layout`。页面队列可以混用模板；当前页随时换模板，不影响其他已有页面。添加空页可以选择初始模板和数量（1–100），之后逐页调整。
5. 换模板保留对应槽位的照片、旋转、镜像、填充模式和取景偏移。缩减模板时，超出容量的非空槽位按原顺序移到紧邻的新增页面，不删除照片状态；新增页面采用目标模板。增加容量则补空槽。
6. 批量导入从当前页开始填入后续空位，保留已有照片，尊重各页模板。容量不足时追加当前页模板的新页面。单张拖到具体槽位可以替换照片。
7. 导出设置属于已有项目模型，保存重开恢复。批量重复导出自动更换整批文件名前缀，保存失败明确报告已完成页数。项目文件仍为 v1，相纸尺寸、预设坐标、EXIF、预览与导出同源等底层合同继续有效。

## 取舍与边界

- 独立页面比“一个项目固定一个模板”更符合真实拼版，但必须处理缩减布局时的照片保全及页索引缓存换代。
- 照片会继承取景参数；槽位比例变化后构图可能不同，用户可以拖动或复位取景。
- 背景和导出设置仍为项目级，模板及照片状态为页面级。暂不新增跨页拖动、自由槽位编辑、修图或边框系统。
- 自定义字体以本机 MiSans 为优先，缺失时回退 Microsoft YaHei UI；字体打包不作为本次美术改版的隐含完成事实。
- 自动测试与界面渲染检查证明对应行为，不能替代所有者操作验收或实际相纸打印。
