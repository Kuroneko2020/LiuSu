# ADR-0011：美术效仿对象定为 RhineLabUI，J 稿降级为过程草稿

- 状态：Accepted
- 日期：2026-10-08

美术效仿对象和 J 稿的证据等级继续有效。全控件亚克力参数及本次任务逐稿审批约束由 [ADR-0013](ADR-0013-照片工作台与逐页模板.md) 替代，按新的界面设计基准实施。

## 背景

[ADR-0007](ADR-0007-技术栈与界面方向.md) 决策 2 确立"设计稿先行"流程，写明"界面实现以选定的风格稿为验收参照"；[ADR-0009](ADR-0009-界面设计语言亚克力展示板.md) 据此把 J 稿记为定稿与验收参照，并把质感参照写为"所有者提供的游戏内亚克力展示框图像"。

所有者最新裁定（2026-10-08）更正上述口径：

1. 美术上的主要效仿对象是 [RhineLabUI](https://github.com/LBEILC/RhineLabUI)（莱茵生命 PV 终端复刻）；J 稿只是过程草稿，不是定稿，也不作验收参照。
2. ADR-0009 中"参照图"实指所有者《CoreKeeper 烹饪攻略 v4.3·层叠玻璃版》成品页（`references/CoreKeeper烹饪攻略-v4.3-层叠玻璃版.html`），并非游戏内展示框图像。
3. RhineLabUI 留存本地只读副本 `references/RhineLabUI/`（与 GitHub 仓库同提交 `3664b4a`，含完整历史），供实现时翻阅。

## 决策

1. **主要美术效仿对象**定为 RhineLabUI，本地只读副本 `references/RhineLabUI/`。
2. **质感参照**定为《CoreKeeper 烹饪攻略 v4.3·层叠玻璃版》成品页（`references/CoreKeeper烹饪攻略-v4.3-层叠玻璃版.html`）。
3. **J 稿**（`docs/设计/设计稿-J/`）降级为过程草稿留档，不作定稿、不作验收参照。
4. **界面观感验收口径**：RhineLabUI 效仿方向 + [界面设计基准](../设计/界面设计基准.md)参数为准，所有者最终裁定。
5. 本 ADR 替代 [ADR-0007](ADR-0007-技术栈与界面方向.md) 决策 2 末句"界面实现以选定的风格稿为验收参照"的验收口径；"设计稿先行、所有者选定"的流程本身仍有效。[ADR-0009](ADR-0009-界面设计语言亚克力展示板.md) 的背景与决策 3 已按所有者明示要求就地更正，与本 ADR 一致。

## 结果

好处：

- 验收有稳定外部对照物：RhineLabUI 本地副本不随草稿迭代变动，跨会话可复核。
- 参照来源与文件路径明确，效仿对象、质感参照、过程草稿三者职责不再混淆。

代价：

- RhineLabUI 是 Three.js/Web 实现，材质思路移植 QML 需按界面设计基准第四、五节参数落地，不是逐像素对照，动效仍需逐项核对。

## 被替代方式

若效仿对象或验收口径再变，创建新的 Accepted ADR 并更新界面设计基准，将本 ADR 状态改为 `Superseded`。
