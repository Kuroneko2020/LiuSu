# ADR-0001：模板与边框分层

- 状态：Accepted
- 日期：2026-06-10

## 背景

留素需要支持二 / 四 / 九基础拼版，同时用户希望加入胶片尺孔。未来还可能加入白边、拍立得边、装饰线、其它孔洞或纸张效果。

如果把胶片尺孔做成模板变体，就会出现“二张胶片模板、四张胶片模板、九张胶片模板”。以后每增加一种边框，都要和所有模板相乘，维护成本会持续放大。

## 决策

模板和边框分层：

- 模板负责照片槽位数量、位置和比例。
- 边框负责胶片尺孔、白边、拍立得边、孔洞、线条和留白。
- 裁切标记独立于模板和边框。

## 结果

好处：

- 胶片尺孔可以复用到二 / 四 / 九模板。
- 未来新增边框不需要复制模板。
- 渲染顺序更清楚。
- 缓存 key 和项目文件模型更容易表达。

代价：

- 需要先设计边框规格模型。
- 边框是否占用照片区域必须显式表达。
- UI 需要同时展示模板选择和边框选择。
