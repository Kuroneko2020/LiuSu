# ADR-0005：第一阶段范围调整——边框系统与胶片尺孔延后

- 状态：Accepted
- 日期：2026-10-07

## 背景

原第一阶段范围包含"可扩展边框系统第一版，胶片尺孔作为首个重点边框规格"。所有者 2026-10-07 决定：胶片尺孔暂不开发。本 ADR 调整第一阶段范围，使首批交付更小、更快可用。

## 决策

1. 胶片尺孔移出第一阶段；可扩展边框系统整体延后。
2. 模板与边框分层的架构决策（[ADR-0001](ADR-0001-模板与边框分层.md)）不变。第一阶段实现页面模型时，只需保证未来能无损接入页面级/槽位级边框层（例如渲染顺序预留边框层位置），不实现边框规格模型、边框 UI 和边框相关缓存参数。
3. 第一阶段聚焦：页面档案模型、二 / 四 / 九模板、图片导入、槽位编辑（旋转、镜像、填充、裁切偏移、替换）、背景设置、多档位 PPI 导出、最小项目保存 / 打开、测试与样张验证。
4. 边框需求再次出现时，按 ADR-0001 的分层接入，不需要重新设计模板系统。

## 结果

好处：

- 第一阶段交付更小，能更快拿到可打印、可裁切的实际成果。
- 避免在核心排版未验证前并行开发边框系统。
- 缓存 key 与项目文件首版更简单，后续扩展字段属于向后兼容方向的演进。

代价：

- 用户短期内无法排胶片尺孔效果。
- 页面模型需一次预留渲染层级，属于少量提前设计。

## 被替代方式

若所有者重新要求边框进入近期范围，应创建新的 Accepted ADR 调整范围并引用 ADR-0001 的分层架构。
