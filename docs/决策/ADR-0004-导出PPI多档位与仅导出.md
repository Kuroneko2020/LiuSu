# ADR-0004：导出 PPI 多档位，打印方式仅导出

- 状态：Accepted
- 日期：2026-10-07

## 背景

原产品定义中两项待确认取舍：默认导出 PPI 用 300、600 还是用户设置；首版是否需要打印机直连。所有者 2026-10-07 决定：PPI 沿用旧版多档位设定；打印方式只导出照片文件。

旧版实现（`references/LiuSu旧版仅供参考`，只读取证）的档位模型为：300 PPI / 600 PPI / 自定义 PPI 三档，自定义范围 72–1200，默认 300；另有原图导出模式自动使用 PNG 并忽略 PPI。

> 原件已按 [ADR-0012](ADR-0012-删除旧留素项目快照.md) 删除，本段档位模型以文字形式保留并继续有效；需要时按本段数字执行，不要试图回查旧代码。

## 决策

1. 导出 PPI 采用多档位设置，不做单一固定值。首版档位沿用旧版：300 PPI、600 PPI、自定义 PPI（72–1200），默认 300。
2. 默认档位可被打印机档案的推荐密度影响（小米 1S 为 300 dpi），具体交互在实施计划中定。
3. 首版不做打印机直连：应用只负责导出图片文件，打印由系统或外部流程完成。
4. 未来若需要直连打印，另立 ADR，不在本决策范围内预留实现。

## 结果

好处：

- 与旧版使用习惯一致，实现成本低。
- 仅导出的边界清晰：留素不承担打印机驱动、队列和厂商协议的复杂度。
- 300 dpi 档位与热升华机型输出密度一致，600 与自定义档位服务未来机型或高倍留底。

代价：

- 用户需经外部流程完成打印，多一步操作。
- 自定义档位若被滥用（如 72 PPI）可能产生低质量导出；以范围下限 72 与 UI 提示约束，不做复杂校验。

## 被替代方式

若未来所有者要求直连打印或改变档位结构，应创建新的 Accepted ADR 替代本决策对应条款。
