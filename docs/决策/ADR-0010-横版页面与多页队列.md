# ADR-0010：横版页面、旧版预设几何与多页队列

- 状态：Accepted
- 日期：2026-10-07

## 背景

所有者在风格稿迭代中明确：**照片默认横向**，页面应为横版；比例必须参照旧版处理。经核对旧版源码（`references/LiuSu旧版仅供参考/src/services/TemplateLayout.cpp`），旧版几何为：页面 148×100mm 横向；二宫格为两张 60×90mm 竖照双联（边距 7/5mm、中缝 14mm）；四宫格 66×44mm（3:2）×4；九宫格 48×32mm（3:2）×9。

> 原件已按 [ADR-0012](ADR-0012-删除旧留素项目快照.md) 删除，本段几何结论以文字形式保留并继续有效；需要时按本段数字执行，不要试图回查旧代码。

同时，所有者认可的编辑页包含**底部胶片栏 = 页队列**（旧版行为：连续排多页、整队导出），而项目文件 v1 初版是单页模型，需要重定义。

## 决策

1. 页面档案默认**横版 148×100mm**。本条有限替代 [ADR-0003](ADR-0003-页面与打印机档案化.md) 中"100mm × 148mm"的记录方向；相纸物理尺寸不变，仅档案记录方向与默认预览方向改为横版。
2. 预设几何沿用旧版 `TemplateLayout` 的验证值（归一化 = mm/148 或 mm/100）：
   - LY-01 单张全幅：整页 148×100；
   - LY-02 二宫格：左右双联 60×90 竖照 ×2（边距 L/R 7mm、T/B 5mm、中缝 14mm）；
   - LY-03 四宫格：66×44 横照 ×4（边距 4/3mm）；
   - LY-04 九宫格：48×32 横照 ×9（起点 0.667/50/99.333 × 0.667/34/67.333）。
   二宫格保留竖照双联（旧版行为；证件照式拼法，两张横照无法在横版页面填满）。若未来需要横照双联，增加新预设或方向参数，不改这批预设。
3. 项目文件重定义为**多页队列**：顶层新增 `pages` 数组，每页含布局与槽位图片状态；背景与导出设置为项目级。该格式从未对外发布，重定义无迁移成本，`version` 保持为 1（本条即 v1 的最终形态）。
4. 领域层（`src/domain`）与测试同步以上三条；测试锁定预设几何与多页往返序列化。

## 结果

好处：

- 界面预览、设计稿、领域模型、旧版行为四方一致，验收有唯一基准；
- 胶片栏（页队列）有正式的模型位置，多页连续排版成为第一阶段能力；
- 几何数值来自旧版实证，打印裁切效果已被旧版验证过。

代价：

- 项目文件 JSON 结构与 02 子方案初版不同（未发布，无外部影响）；
- 二宫格为竖照是全横版要求下的唯一例外，需在设计基准中显式标注。

## 被替代方式

预设几何若需扩展（新布局、方向参数），创建新的 Accepted ADR；本 ADR 仅约束首批预设与页面方向默认值。
