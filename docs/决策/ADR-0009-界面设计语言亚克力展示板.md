# ADR-0009：界面设计语言确定为亚克力展示板体系

- 状态：Accepted
- 日期：2026-10-07

## 背景

界面风格经多轮设计稿迭代（A 极简浅色、B 深色、C 暖纸、D/E 旧版 LR 式结构、F 玻璃光效、G 档案终端、H 玻璃 3D、I 全应用玻璃），所有者最终选定 J 稿：**乳白亚克力展示板材质体系**，其质感参照所有者提供的游戏内亚克力展示框图像与 [RhineLabUI](https://github.com/LBEILC/RhineLabUI)（莱茵生命 PV 终端复刻）的设计理念。

所有者明确两点关键要求贯穿定稿：

1. 玻璃感必须有**厚度与分层透明度**（这是选择 Qt 的本意，拒绝平面 2D）；
2. 整个软件（主页、编辑页、设置、弹窗、每个控件）统一适配该风格，而非局部点缀。

## 决策

1. 界面设计语言定为：**照片装裱于乳白亚克力展示板后**。核心材质为奶白半透明亚克力板 + 四角金属螺丝 + 可见板缘厚度 + 斜面反光；完整规格见[界面设计基准](../设计/界面设计基准.md)。
2. 建立 `docs/设计/` 目录承载设计文档（文档体系结构演进，经所有者批准）；首个文档为界面设计基准。
3. J 稿（HTML 与截图）作为界面实现的**验收参照**，随仓库入库于 `docs/设计/设计稿-J/`。
4. 界面字体采用 MiSans（小米官方字体，免费商用），回退 Segoe UI / 微软雅黑。
5. 产品隐喻统一：每一页照片即"装裱在一块亚克力展示板后"，该隐喻同时是 UI 风格与产品语义。

## 结果

好处：

- 全应用材质统一（分级透明度 + 同族器件），新界面有明确可循的规范；
- 设计隐喻与产品用途（照片装裱、展示、裁切）天然一致；
- 有入库的验收参照，界面实现不再凭感觉。

代价：

- 亚克力质感（磨砂、板缘、螺丝）需要 QML 分层渲染与自绘，实现成本高于平面样式；
- 设计稿为静态 HTML 示意，动效细节需在实现阶段以 QML 动画落实并逐项核对。

## 被替代方式

若未来调整设计语言，应创建新的 Accepted ADR 并更新界面设计基准，将本 ADR 状态改为 `Superseded`。
