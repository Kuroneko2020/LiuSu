# ADR-0012：删除旧留素项目快照

- 状态：Accepted
- 日期：2026-10-08

## 背景

[ADR-0002](ADR-0002-文档体系迁移与R式治理.md) 把旧留素项目以只读快照形式留在本地
`references/LiuSu旧版仅供参考/`（含 `.git` / `qml` / `res` / `src` / `文档`，不进 Git），
[文档治理规则](../规范/文档治理规则.md)第四节据此把它定位为"查旧行为、旧算法、旧 UI 反例和
旧踩坑"的证据源。

所有者决定对留素做大幅度重构（2026-10-08）。

## 决策

**删除 `references/LiuSu旧版仅供参考/`。**

理由：**因为想大幅度重构，防止受到旧版影响，决定删除。**

`references/` 下的其余材料不受影响，继续保留且仍为只读：

- `references/RhineLabUI/`——当时主要美术效仿对象的本地副本（[ADR-0011](ADR-0011-美术效仿对象与验收口径.md)）；现按 [ADR-0015](ADR-0015-克制材质与稳定内容.md) 仅作局部材质、光感与运动品质参考。
- `references/CoreKeeper烹饪攻略-v4.3-层叠玻璃版.html`——质感参照（同 ADR-0011）。

## 影响面

1. [AGENTS.md](../../AGENTS.md)：事实来源优先级第 3 条改为外部参照材料；项目边界去掉"旧留素项目快照"。
2. [文档治理规则](../规范/文档治理规则.md)第四节：`references/` 只剩外部美术参照，旧项目快照条目移除。
3. [ADR-0002](ADR-0002-文档体系迁移与R式治理.md)、[ADR-0004](ADR-0004-导出PPI多档位与仅导出.md)、
   [ADR-0010](ADR-0010-横版页面与多页队列.md) 中指向旧项目路径的取证引用改为"原件已删除"，
   已提取的文字结论原样保留（ADR 是决策记录，不回改历史结论）。

## 已提取结论不受影响

删除前，从旧项目取出的事实已按文档治理规则第四节"足以支持结论的摘要写进正式文档"落成文字：

- 导出 PPI 档位模型（300 / 600 / 自定义 72–1200，另有原图导出）→ [ADR-0004](ADR-0004-导出PPI多档位与仅导出.md)。
- 页面与槽位几何（148×100mm 横版；二宫格 60×90×2、四宫格 66×44×4、九宫格 48×32×9）→
  [ADR-0010](ADR-0010-横版页面与多页队列.md) 与[界面设计基准](../设计/界面设计基准.md)第八节。

删除只影响"回查旧代码原文"这一条路，不影响上述已固化的结论。

## 结果

好处：

- 重构时不再有旧实现可随手对照，避免把旧结构、旧命名、旧补丁逻辑带进新代码——这正是本次删除的目的。
- `references/` 的语义收窄为"外部美术参照"，边界更简单。

代价：

- 需要追溯旧版细节时无法再读原代码，只能依据 ADR 中的文字结论推导；如确需，只能从旧仓库另行取得，属新决策。
- 本次删除不进 Git（`references/` 本就被忽略），不可通过版本库恢复。
