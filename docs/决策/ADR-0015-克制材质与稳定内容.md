# ADR-0015：克制材质与稳定内容

- 状态：Accepted
- 日期：2026-10-11
- 关系：替代 [ADR-0011](ADR-0011-美术效仿对象与验收口径.md) 的整体效仿及验收口径、[ADR-0014](ADR-0014-空间交互与可扩展目录.md) 决策 1–2 的强空间运动与图像明度反馈要求，并修正 [ADR-0013](ADR-0013-照片工作台与逐页模板.md) 决策 1–2 的美术表达。逐页模板、照片保全、可扩展目录、项目格式和导出能力合同继续有效。

## 背景

所有者认可近期效果图中的厚度、半透明硬质材料、玻璃边缘与光线层次，没有认可其中的布局、功能清单或产品定位。此前整体效仿 RhineLabUI 的口径混淆了材质偏好与适合照片工具的交互方式。首页模板卡片的倾转、抬升与回弹过强；所有者实测反馈工作台图片仍有悬停运动，不能以旧文档声称“固定”作为通过证据。

## 决策

1. 目标是薄而明确的厚度、半透明硬质材料、克制边缘高光和柔和投影；静止也能识别材质。避免夸张挤出边、重复阴影、强光晕、大范围扫光及整屏泛白，也不退回只有纯色矩形与细描边的普通扁平卡片。
2. RhineLabUI 保留为局部材质、光感与运动品质的参考，不再强制效仿整体界面形态与交互。所有者本次附图仅为大致质感参照，不是布局规格、功能清单或整体目标；图中海报、文字、贴纸等不构成开发授权。J 稿等过程材料继续保留历史身份。
3. 按内容职责判断：容器、导航、工具与选择器可以承载材质和轻微光线响应，保留轻重层级，避免层层套板。照片、纸面及需要比较、取景、精确操作的内容保持清楚稳定；不得被材质蒙雾、染色或反光遮挡。装饰与成品渲染分离，不进入导出。
4. 沿用当前主页基本组织和功能，模板卡片以稳定、可比较、可选择为先。优先通过细微高光、描边、阴影变化反馈，去掉不必要的倾转、抬升和回弹；不机械缩小卡片。保留搜索、滚动、目录扩展，不将当前四个模板固化为产品边界。首页是软件入口，不靠大标语、场景背景和装饰留白撑设计。
5. 工作台照片与纸面在指针进入、停留、移动、离开及经过边缘时，位置、尺寸、朝向和照片像素保持稳定。检查图片、纸面及完整祖先容器链，不能仅固定命中框。选中框、必要提示与拖放提示可保留；用户主动取景、旋转、换页等必要内容变化继续有效。不得用照片明暗变化表现容器材质。
6. 材质允许视觉近似，不要求真实折射或完整三维建模；技术取舍服务于实际观感、交互稳定与性能。静止无持续装饰动画，悬停不重新解码或计算导出。
7. 本决定不固定最终导航、工具栏、检查栏、队列位置或首页结构，不一次性将全部控件改为玻璃；未确认的布局、材质细节继续待验证。所有者已授权本轮集中修改，不要求再以整套效果图审批作为实施前置条件。

## 取舍与验证边界

减少空间运动后，材质主要依靠静态层次与局部光线表达，必须在真实 QML 画面中检查清晰度和可读性。几何和照片像素的逐帧检查可以发现父容器带动、缩放或遮色，不能替代美术与桌面手感验收。应同时复测静止/悬停/快速移入移出、选中、取景、换页、换模板及导出隔离，提供实际运行截图或运动帧；静态截图不能证明悬停稳定。

方向纠正与近期界面收敛不等于整套新美术定稿。运行证据、限制及所有者验收只记入[总跟踪 Issue](https://github.com/Kuroneko2020/LiuSu/issues/1)。
