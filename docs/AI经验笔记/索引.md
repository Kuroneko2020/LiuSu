# AI经验笔记索引

本目录按主题沉淀可复用的协作方法与经验，纳入 Git。这里不是当前事实来源，也不具独立裁定权；若某条经验变成必须遵守的边界，应提炼进 `docs/规范/` 或测试，并从本索引链接过去。

经验笔记按主题原地更新；新证据推翻结论时更新或标明替代，不按会话日期新建副本。

## 当前条目

- [大任务基准与子方案拆分法](大任务基准与子方案拆分法.md)：把容易上下文爆炸的大任务拆成“基准文档 + 多个小子方案 + 最终收口”的协作方法，适合多会话接力。
- [交接职责脚本化](交接职责脚本化.md)：调整文档入口职责时，不能只改文案，还要同步路由和治理规则，防止废弃入口回流。

## 排查复盘的写入约定

出现真实排查复盘时，直接在本目录新建主题文件并登记到本索引。只有具备复用价值的问题才值得写入：未来 AI 容易再犯、定位成本高、或能提炼出规则 / 测试 / 审计。

推荐结构：

```text
# 问题标题

## 现象
## 根因
## 错误路线
## 正确排查顺序
## 已提炼到哪些规则 / 测试 / 审计
```
