# 文档目录

最后人工/AI 更新：26-06-10-1727

本文是 `文档/` 的入口地图，用来判断遇到问题时该读哪份文档。本文只写目录职责，不承载具体版本、当前 bug、验收结论或完整工程规则。

## 冷启动阅读顺序

1. 根目录 `AGENTS.md`
2. `文档/冷启动说明.md`
3. `文档/更新记录/索引.md` 最近 3 次记录
4. 当前任务相关的项目规则、产品定义、当前计划或经验笔记

## 顶层目录职责

| 位置 | 性质 | 负责 | 限制 |
| --- | --- | --- | --- |
| `冷启动说明.md` | 短交接路线 | 默认阅读顺序、条件阅读入口、暂停边界 | 不写功能百科、历史流水、当前 bug 总表 |
| `产品定义.md` | 产品锚点 | 产品是什么、第一阶段范围和非范围 | 不写实现细节流水 |
| `项目规则/` | 硬规则 | 工程红线、尺寸渲染、边框模板、缓存、UI、测试交付 | 不写历史复盘和当前计划细节 |
| `当前在做计划/` | 当前执行计划 | 仍在推进或待执行的分阶段计划 | 完成、失败或废弃后归档 |
| `AI经验笔记/` | 经验库 | 协作方法、排查复盘、架构决策背景 | 不覆盖当前事实和硬规则 |
| `更新记录/` | 历史账本 | 每轮更新的目标、范围、验证、未做事项 | 不写成长篇功能百科 |
| `归档历史计划/` | 历史计划归档 | 已完成、失败、废弃或替代的计划 | 不作为当前执行路线 |
| `文档规则/` | 文档系统规则 | 目录职责、写作规范、参考隔离 | 不写产品功能细节 |

## 常见任务读哪里

| 任务 | 先读 | 再按需读 |
| --- | --- | --- |
| 想知道现在做到哪 | `更新记录/索引.md` 最近记录 | 当前计划、真实文件 |
| 新 AI 接手 | `AGENTS.md`、`冷启动说明.md` | 相关规则和当前计划 |
| 写或改规则 | `文档规则/文档书写规范.md` | `项目规则/`、更新记录 |
| 做胶片尺孔 | `项目规则/边框与模板规则.md` | `产品定义.md` |
| 做导出 / 打印 | `项目规则/尺寸与渲染规则.md` | `产品定义.md` |
| 做图片缓存 | `项目规则/图片与缓存规则.md` | 相关测试与复盘 |
| 做 UI 重绘 | `项目规则/UI规则.md` | `产品定义.md` |
| 拆大任务 | `AI经验笔记/协作方法/大任务基准与子方案拆分法.md` | 当前计划目录 |

## 命名规则

- 新文档默认使用中文目录名和中文 Markdown 文件名。
- 正式说明文档页眉使用：`最后人工/AI 更新：yy-MM-dd-HHmm`。
- 当前计划目录内使用：`00-基准.md`、`01-...md`、`02-...md`、`最后-验证与收口.md` 或等价编号。
- 更新记录文件名建议：`版本号-简短说明-yymmddHHmm.md`。

## 维护重点

1. 新会话默认只读入口，不通读全仓文档。
2. 一个事实只有一个主来源；其它文档只写摘要和链接。
3. 旧参考资料不自动成为当前规则。
4. AI经验笔记若反复影响交付，应提炼到项目规则、测试或审计。
5. 当前计划完成、失败或废弃后必须离开 `当前在做计划/`。
