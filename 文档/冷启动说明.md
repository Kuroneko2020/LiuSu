# 冷启动说明

最后人工/AI 更新：26-06-10-1727

本页用于新 AI 接手留素时快速进入状态。不要把本页写成项目百科；它只负责读取顺序、任务分流和必须暂停的边界。

## 默认读取顺序

1. 根目录 `AGENTS.md`。
2. 本文件。
3. `文档/更新记录/索引.md` 最近 3 次记录，并打开对应记录文件。
4. 如果当前任务属于某个计划，读取 `文档/当前在做计划/<计划名>/00-基准.md` 和本轮指定子方案。
5. 按任务类型读取对应 `项目规则/`、`产品定义.md` 或 `AI经验笔记/`。

## 当前事实入口

本页不维护当前阶段、版本或完成状态。需要判断当前做到哪一步时，只看 `文档/更新记录/索引.md` 最近记录、真实文件和用户最新反馈。

## 必读底线

留素五个工程底线是：性能底线、功能底线、注释底线、指令底线、职责边界底线。完整内容见 `AGENTS.md` 和 `文档/项目规则/工程规则.md`。

## 按任务加读

- 文档整理：`文档/文档规则/目录.md`、`文档/文档规则/文档书写规范.md`。
- 旧项目参考：`文档/文档规则/参考资料隔离规则.md`。
- 产品范围或首版取舍：`文档/产品定义.md`。
- UI 重绘：`文档/项目规则/UI规则.md`。
- 6 英寸相纸、PPI、导出：`文档/项目规则/尺寸与渲染规则.md`。
- 胶片尺孔、拍立得边框、装饰边：`文档/项目规则/边框与模板规则.md`。
- 图片导入、EXIF、缩略图、缓存：`文档/项目规则/图片与缓存规则.md`。
- 大任务拆分：`文档/AI经验笔记/协作方法/大任务基准与子方案拆分法.md`。

## 必须暂停或显式说明风险的边界

- 改相纸物理尺寸、默认 PPI、导出像素尺寸或打印缩放口径。
- 把边框孔位、胶片尺孔或装饰元素硬编码到二 / 四 / 九模板中。
- 让 QML 页面直接决定最终导出坐标、孔位或图片裁切。
- 改缓存 key 但没有说明旧缓存失效策略。
- 复制旧项目代码但没有说明来源、差异、风险和测试。
- 把多个职责塞进单个控制器、单个 QML 页面或单个服务。

## 交付纪律

- 只整理 Markdown 时，不需要构建；最终回复说明“本轮只整理文档”。
- 改源码后必须构建，并说明构建命令和结果。
- 涉及导出结果时，优先用固定输入图片生成可复核样张或快照测试。
- 每轮结束检查是否有经验笔记需要新增；高价值经验先写 `AI经验笔记/`，反复出现后提炼成 `项目规则/`、测试或审计。
