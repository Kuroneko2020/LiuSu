# 产品定义

最后人工/AI 更新：26-06-10-0000

## 一句话定义

留素是桌面端照片拼版工具，用于把多张照片快速排到 6 英寸相纸上，导出后打印并裁切。

## 核心用户目标

- 快速导入照片。
- 在固定相纸尺寸内选择二 / 四 / 九等拼版模板。
- 对每个槽位做旋转、镜像、填充、裁切偏移和替换。
- 叠加可扩展边框，例如胶片尺孔、白边、拍立得边、裁切辅助线。
- 保证预览、导出、打印前检查一致。
- 输出适合打印的图片文件。

## 第一阶段范围

- 6 英寸相纸页面模型。
- 二 / 四 / 九基础模板。
- 图片导入、槽位填充、槽位编辑。
- 背景色或基础背景设置。
- 可扩展边框系统第一版，胶片尺孔作为首个重点边框规格。
- 导出图片。
- 最小项目保存 / 打开能力。
- 最小测试与样张验证。

## 第一阶段明确不做

- 不做复杂修图：磨皮、滤镜市场、调色曲线、局部修复。
- 不做云同步、账号系统、素材商城。
- 不做大型图库管理。
- 不做移动端。
- 不把旧项目 UI 原样保留；UI 可以重新设计。
- 不把旧项目代码视为可直接复制的事实来源。

## 核心设计判断

- 模板负责照片槽位布局。
- 边框负责装饰、孔洞、线条、留白、胶片尺孔等外观层。
- 裁切标记负责打印裁切辅助。
- 渲染引擎负责把页面模型转换成预览图、缩略图和导出图。
- UI 负责操作入口和状态展示，不负责最终几何真相。

## 待用户确认的产品取舍

- 默认 6 英寸相纸是否沿用旧项目的 `148mm × 100mm`。
- 默认导出 PPI 使用 300、600，还是做成用户设置。
- 胶片尺孔第一版是否只做横向胶片边，还是同时支持竖向胶片边。
- 首版是否需要打印机直连，还是只导出图片后由系统 / 外部软件打印。
