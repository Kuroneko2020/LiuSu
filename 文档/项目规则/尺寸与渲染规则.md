# 尺寸与渲染规则

最后人工/AI 更新：26-06-10-0000

本文规定相纸尺寸、坐标系统、PPI、预览、缩略图和导出的同源规则。

## 核心结论

预览、缩略图和导出必须共享同一套页面模型和渲染管线。允许预览使用低分辨率缓存，但不允许预览和导出使用两套几何算法。

## 相纸尺寸

- 6 英寸相纸的物理尺寸必须由统一配置或统一函数提供。
- UI、预览、导出和测试不得各自硬编码尺寸。
- 旧项目使用过 `148mm × 100mm`；新项目是否沿用需用户确认。
- 未确认前，文档可以把 `148mm × 100mm` 写为“旧项目参考值”，不能写成新项目已最终确认事实。

## 坐标系统

推荐同时保留三种口径，但主来源必须清楚：

| 口径 | 用途 | 规则 |
| --- | --- | --- |
| 物理尺寸 mm | 打印、导出、模板设计 | 页面真实尺寸主来源 |
| 归一化坐标 | 模板和边框规格复用 | 不受 PPI 影响 |
| 像素坐标 px | 最终预览和导出位图 | 由 mm + PPI 派生 |

不得让屏幕像素、QML item 尺寸或窗口大小反向决定真实页面几何。

## PPI 规则

- PPI 是导出参数，不是 UI 缩放参数。
- 默认 PPI 需要由产品定义或设置规则确认。
- 导出像素尺寸必须由物理尺寸和 PPI 推导。
- 300 PPI 与 600 PPI 输出应只改变像素密度，不改变照片槽位的物理比例。

## 渲染同源

以下输入必须对预览、缩略图、导出一致：

- 页面尺寸。
- 模板槽位矩形。
- 背景。
- 图片 EXIF 方向。
- 旋转、镜像、填充模式、裁切偏移。
- 边框规格和边框参数。
- 边框绘制顺序。
- 裁切标记。

## 绘制顺序

推荐基础顺序：

1. 页面背景。
2. 模板槽位底色或占位。
3. 槽位图片。
4. 单槽位遮罩或内边框。
5. 页面级边框，例如胶片尺孔。
6. 裁切辅助线。
7. 仅 UI 可见的选中框、拖拽手柄、提示层。

第 7 层默认不进入导出，除非明确属于导出选项。

## 测试要求

涉及尺寸和渲染的修改至少应覆盖：

- 固定页面尺寸下的导出像素尺寸测试。
- 二 / 四 / 九模板槽位数量和边界测试。
- 同一页面模型下预览与导出使用同源数据的测试。
- 边框叠加不改变照片槽位几何的测试。
- EXIF 方向样本测试。
